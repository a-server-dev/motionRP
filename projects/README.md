# Studio projects

保存先は `projects/<id>/project.json` と `projects/<id>/models/*.bbmodel` です。
Webエディタで書き出したZIPを展開し、この構成でPRを作成してください。
PRの検証・ビルドは管理者の承認待ちになる場合があります。取り込みは自動ではありません。

`enabled: true` のプロジェクトはJARとリソパへ組み込まれます。
`example` はサンプルで、通常のゲーム内カタログへは追加されません。
編集画面のプレビューは簡易表示であり、BetterModel/Minecraftでの最終確認も行ってください。
