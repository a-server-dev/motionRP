# ブロリーの岩盤：二人用演出

招待者が攻撃側、承諾者が相手役になる、約7.2秒の二人用演出。

```
/motionrp broly [相手]
/motionrp broly accept <招待者>
/motionrp broly cancel
```

0.35.0から `/motionrp give motion broly` で登録用アイテムを配布できる。モーションセットに登録・選択して左クリックすると、8ブロック以内の一番近いプレイヤーに招待する。相手名なしの `/motionrp broly` も同じ。承諾は `/motionrp accept`、チャットの `(accept)` クリック、またはモーションセットの右クリックで行える。持ち替えてから右クリックしても招待は残る。

二人とも同じワールドの8ブロック以内で地上に立つ。招待は30秒。承諾するまで移動しない。フュージョンの招待とは区別し、重複して二人用演出に参加することはできない。

0.33.0では添付の「ふおぉ！？（岩盤）」動画を参考に、受ける側が実際に承諾した地点から開始する。実行者から受ける側へ向かう方向へ、二人とも約0.6秒で地面から約1.15ブロック浮き、受ける側が約1.4秒かけて4ブロック逃げる。足踏みの走行ではなく、膝を曲げて脚を後方へ流した舞空術の姿勢を保つ。頭を先に振り返らせ、約0.6秒で身体も向き直って驚く。その後に実行者が約0.5秒で突進し、短く頭をつかんで押し飛ばす。逃走の前に受ける側を別の開始位置へ配置し直すことはしない。逃走の途中が塞がっている場合は手前で止まって振り返り、突進側が進めない場合は二人を復帰させて中断する。

飛行に入った後は、飛行の各区間を、相手の体の幅と頭・胴・足元の高さでブロックに向けてレイ判定する。実際のプレイヤーの衝突判定も使い、壁や細い柵の手前で止める。移動先だけを見る判定ではないため、速い飛行でも壁を飛び越さない。

進行方向に壁がなければ、飛行開始地点から24ブロック先に演出用の岩盤を出す。衝突すると亀裂のある岩の縁、飛び散る破片、粉塵と風圧を表示し、相手がよろける。岩盤と亀裂はモデルで、実際の地形やプレイヤーの体力は変更しない。読み込み済みの範囲やワールド境界を超える場合は中断する。

表示する人は `/motionrp view on` が必要。通常終了、どちらかの中止・被ダメージ・死亡・退出・外部テレポート・プラグイン停止では、双方の表示と飛行状態を片付ける。通常は両者をそれぞれ元の場所へ戻す。外部テレポートではその行き先を尊重し、他方を戻す。退出時に復帰できなかった人は、再ログイン時に保存した復帰情報を使う。

`tools/generate_broly.py /path/to/pinned/steve.bbmodel` で二人のポーズと岩盤・亀裂モデルを再生成できる。可変の衝突時刻に合わせて flee / turn / charge / fright / grapple / flight / impact / recover を切り替える。終了はポーズの終端ではなく、演出全体の時計とタイムアウトで管理する。

ナルトVSサスケのモデルや演出データは保持し、保留中の実行コマンドは再公開していない。

## 0.34.0の岩盤

未破壊の灰色岩壁と、凹んで亀裂の入った岩壁を別メッシュとして用意。衝突時に後者へ切り替え、Z方向の奥行きを約0.3秒で広げる。外周はほぼ同じ位置を保ち、中心が奥へ沈むため、粒子の輪を置くだけの表現ではない。円形の口は直径約8.5ブロック、中心の深さは約2.55ブロック、岩壁全体の幅は約15.3ブロック。灰色の破片と粉塵、隆起した縁、枝分かれする放射状の亀裂も追加した。

逃走中は約1.15ブロックの浮遊を保ち、衝突に向かう飛行ではゆるやかに上昇する。円形の口の下端が地面に埋まらないよう、衝突時は足元を元の地面から約3.2ブロック、くぼみの中心を約4.5ブロックの高さへ合わせる。演出用岩盤のときは、衝突後に両者を最大2.4ブロックだけくぼみの内側へ進める。実際のブロックに衝突した場合は中へ入れず、実ブロックの手前にくぼみ付きの岩壁を重ねて見せる。地形を掘ったり、ブロックを書き換えたりはしない。
