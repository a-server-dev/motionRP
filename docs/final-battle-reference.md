# ナルト VS サスケ 最終決戦：参照資料と演出構成

2026-11-20 の依頼に基づく、二人用のオリジナル3Dモーション。

## ネット上で確認した資料

- [NARUTO公式：最後の戦い](https://naruto-official.com/en/anime/naruto2/list/01_920)（通算696話／疾風伝476話）：対峙から九喇嘛・須佐能乎を使った戦いに入る場面。
- [NARUTO公式：ナルトとサスケ](https://naruto-official.com/en/anime/naruto2/list/01_921)（通算697話／疾風伝477話）：三面六臂の九喇嘛が金色と黒紫の二つの球を掲げる画像、青白い雷を帯びた須佐能乎の画像を確認。
- [Naruto: Shippuden season 21 – Episodes 476–477](https://en.wikipedia.org/wiki/Naruto:_Shippuden_(season_21))：分身による自然エネルギーの収集、九喇嘛の合流、尾獣のチャクラを集めた須佐能乎、二つの巨大螺旋手裏剣とインドラの矢の衝突、巨大な爆発と渦の流れを照合。

0.29.0では添付動画「六道・超大玉尾獣螺旋手裏剣vsインドラの矢」（39.87秒）も確認。0–6秒の掲球と構え、6–10秒の雷の弓と双方の射出、10–26秒の接触・巨大な光球、26–40秒の螺旋雲と地表へ広がる風を参照した。添付動画そのものは配布物に含めていない。

公式サイトの場面画像・公開あらすじ・添付動画を基に、操作・観戦できる約44秒の演出へ再構成した。資料画像や動画自体はプラグイン・配布物に含めていない。

## 共有する時系列（20tick/秒）

| 時間 | 内容 |
| --- | --- |
| 0–2秒 | 二人が向かい合い、金と紫のチャクラが出現 |
| 2–7秒 | 九本の尾を持つ九喇嘛と、翼のある須佐能乎が成長。参加者を頭部付近へ移動 |
| 7–12秒 | 両者が腕を胸元へ引き、チャクラを集める構え |
| 12–16秒 | 二体の九喇嘛の分身が合流。九つの尾獣チャクラが須佐能乎へ集まる |
| 16–20秒 | 三面六臂の九喇嘛とインドラ須佐能乎へ変化 |
| 20–23秒 | 両腕を掲げる・弓を引く構えを作る |
| 23–26秒 | 手元と弓に二つの螺旋手裏剣とインドラの矢が成長 |
| 26–28秒 | 技を保持して溜め、27.6秒から振りかぶる |
| 28–30秒 | 頭上からの投擲と弓弦の解放。上半身の反動と技の飛翔 |
| 30–36秒 | 空中で衝突し、光球・雷・渦状の暴風が広がる |
| 36–44秒 | チャクラが消え、二人が降下して元の位置へ戻る |

## 操作と表示（保留中）

0.31.1で実行コマンドを取り下げた。以下は再開時のために残した仕様で、現在は実行できない。モデル・モーション・演出コードは保持している。

招待者がナルト役、承認した相手がサスケ役。

```
/motionrp finalbattle <相手>
/motionrp finalbattle accept <招待者>
/motionrp finalbattle cancel
```

招待は30秒、二人とも8ブロック以内で地上に立っている状態で承認する。招待だけでは移動しない。フュージョンの招待を最終決戦として承認することも、その逆もできない。

演出中は二人を約116ブロック離して配置し、最大約75ブロック上空へ移動するため、広く上空の空いた場所で使う。位置・飛行状態の復帰記録は既存のフュージョンと同じ仕組みを使用する。明示的な中止、被ダメージ、死亡、退出、外部テレポート、プラグイン停止では両者をまとめて終了する。外部テレポートはその行き先を優先し、他方は元の位置へ戻す。

見る人は `/motionrp view on` が必要。参加者は距離にかかわらず互いの演出を受信し、観戦者の表示範囲は会場中央と `visibility.range` を基準にする。表示OFFの人にはモデルとパーティクルを送らない。

爆発や雷は演出用で、地形の変更や対戦相手へのダメージは発生させない。

## モデル編集

`tools/generate_final_battle.py /path/to/pinned/steve.bbmodel` で専用モデルと二人のモーションを再生成できる。九喇嘛の九本の尾・三つの頭・六本の腕、須佐能乎の翼と弓、二種類の螺旋手裏剣、矢、衝突球、地面から伸びる螺旋の暴風は個別のBBmodelに分かれている。

## 0.30.0のビジュアル更新

- 立体メッシュの生成は `tools/generate_battle_visuals.py` が担当し、既存の骨・回転軸・再生時間を保持する。`generate_final_battle.py` から四つの巨体と全エネルギーモデルをまとめて再生成する。
- 九喇嘛は連続した曲線断面の体と尾、三面六臂の筋肉、獣の脚と爪、開く口と牙、瞳孔・頬・額の紋様。須佐能乎は厚みのある面取り装甲、天狗面と翼、独立した指のある籠手。
- エネルギーの表面は24×48の球面分割と流れる筋。外縁の透け感は部分アルファに依存せず、256×128の材質テクスチャに0/255アルファの細かな抜き模様を使う。特別なシェーダーは必要ない。
- 一モデル45,000三角形を上限としてテスト。モデルの動く部品数を抑え、尾・腕・翼と弓の既存の同期を維持する。新しいモデルへの自動更新とカスタムモデルの保持をテストしている。
- [形状確認用のプレビュー](images/final-battle-030.png)は生成した頂点から描いた図で、Minecraftの描画結果を撮影したものではない。

## 0.31.0の変更

六本の腕は左右別に一つの肩を共有。須佐能乎の横幅は84%、頭部はさらに75%、脚は120%へ変更し、肩・手・弓・参加者の位置を合わせ直した。頭と胴は首で接続する。衝突前の打撃と先行する爆発を廃止し、チャクラ収集、変身、構え、技の形成、保持、投擲と射出、飛翔、衝突を順番に再生する。専用の release クリップは発射8tick前に始まり、発射後には上半身が反動する。

衝突球と暴風の表示スケール、爆発雲の広がりは0.30.0比で約3倍。地形や体力への影響はない。上空80ブロックの余裕を開始条件とする。
