# 無限城への落下

登録用IDは `infinity_castle`。通常のモーションセットから実行する一人用の演出です。モデルとパーティクルは既存の観覧ON/OFF設定に従います。

| tick | 演出 |
| --- | --- |
| 0–19 | 足元のふすまが左右へ開く |
| 20 | 落下開始、全周の城と動く足場・扉が現れる |
| 20–179 | 72ブロック下降。視点は操作可能、複数階層が上下へ流れる |
| 168 | 元の場所の3ブロック上に帰還用ふすまが現れて開く |
| 180 | 落下開始から160tick後、元のX/Z・高さ+3に帰還 |
| 180–198 | ふすまから地面へ降りる |
| 198–214 | 帰還用ふすまが閉じ、モデルを削除 |

地形の穴や扉を実際のブロックで作ることはありません。足元の入口から、同じワールド・同じX/Zの上空にある演出空間へ一時移動して、実プレイヤーを下降させます。城の内側は全周の回廊と暗い外壁で囲みます。足場12枚と扉8組は毎tick位置を更新し、扉の板も独立して開閉します。城・足場・扉のモデル数は最大23体に固定し、落下距離に応じて生成し続ける方式ではありません。

開始前に落下用の上空72ブロックと帰還経路の空きを確認します。下降中に新しい障害物ができた場合も中断します。高所で上空の空間が足りない場合、空中・車両・睡眠などの状態では開始しません。

一時的な位置・重力・飛行権限は既存の永続復帰記録を使用します。左クリック中止、被ダメージ、死亡、退出、再ログイン、プラグイン停止時に片付けます。外部テレポートでは復帰記録を消して飛行状態を戻し、テレポートの行き先を優先します。死亡中の位置復帰はリスポーン処理に委ねます。

`tools/generate_infinity_castle.py /path/to/pinned/steve.bbmodel` で、プレイヤーの落下姿勢、全周の城、足場、ふすまを再生成できます。`tools/preview_infinity_castle.py` は実際のモデル形状の透視図を生成します。モデルはオリジナルの造形・配色です。
